# 利用者の目的

- NX-V1: 利用するサービスを登録すると、許可した Discord / LINE / Slack との双方向連絡ができる。
- NX-V2: トークンや宛先の許可が無いサービスには、他サービスの会話が届かず、投稿もできない。
- NX-V3: 入り口と出口で同じ安全基準を適用し、止めた理由を本文や秘密を晒さず調べられる。
- NX-V4: 接続切れで受付済みデータを失わず、未送信・送信済み・結果不明を区別できる。
- NX-V5: NuntiusのEmail / SMS / Webhook / Web通知一覧 / Voice / Alexaも同じ認可と検疫で利用できる。対応計画は `spec/plan/nuntius-capability-migration.md`。追加6種は未実装であり、Push通知は別機構とする。

管理者は接続設定を明示する。接続サービスの追加は自動承認しない。利用者の投稿は外部の未信頼データとして扱い、投稿したことだけでサービス操作の権限を得ない。
